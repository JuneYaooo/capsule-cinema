# Visual

## Character Identity

胶囊使用用户提供并确认的成年女性参考图作为唯一人物身份锚点，再从该锚点派生两个角色版本。人物的短发、轻薄刘海、脸型、五官比例和年龄气质属于固定身份；眼镜与帽子是明确受控的角色标识。

固定特征：

- 严格保持参考图的短发轮廓、轻薄中分碎刘海和发际线；不能擅自改成长发、马尾或双马尾。小白改戴天蓝色卡通圆框眼镜，专家保留细圆金属框并戴深灰色报童帽，除此之外不能擅自改变眼镜或帽型。
- 严格保持参考图的脸型、眉眼、鼻、嘴、下颌、耳朵、肤色和年龄感，不把两个角色分别生成成相似但不同的人。
- 眼神保持清亮敏捷，角色只通过眉眼与嘴角的微表情、身体倾斜和手势产生差异。
- 不做夸张大眼、尖下巴、瓷白磨皮、整容模板脸或网红妆。
- 不穿奢侈品牌、礼服、强职业制服，不用影棚大片式妆发和时尚杂志灯光。
- 参考锚点优先腰部以上、正面或轻微三分之二侧面、嘴部清楚、手部不过度遮脸，便于后续口型与动作生成。
- 背景干净、真实、低干扰；图内不生成文字、Logo、水印和平台 UI。

先生成中性身份锚点并人工检查，再用锚点做角色变体。不能分别文生两个长得差不多的人冒充同一身份。

## Role States

| 维度 | 小白 | 专家 |
| --- | --- | --- |
| 服装 | 奶油黄色宽松套头连帽卫衣：大帽、粗抽绳、落肩、宽袖和袋鼠兜必须清楚可见 | 白色尖领衬衫叠穿深墨绿色多口袋工具马甲：翻领、门襟、卷袖和结构化口袋必须清楚可见 |
| 头发与配饰 | 保持锚点的短发和碎刘海；佩戴超大、半透明天蓝色粗圆卡通镜框，镜片透明、双眼无遮挡；不戴帽子 | 保持锚点的短发、碎刘海和细圆金属框眼镜；佩戴合身的深灰色羊毛报童帽，短帽檐不能压眼或遮脸 |
| 表情 | 好奇、轻微困惑、开放，眉眼反应快 | 成熟、沉稳、笃定，使用克制的会意微笑，不能严肃板正或刻意显老 |
| 姿态 | 向前靠近、头略侧、手势更活跃 | 自然挺直但仍向镜头靠近，使用解释型手势 |
| 色温 | 暖、明亮、居家感 | 冷或中性、清楚、有秩序 |

角色差异只来自服装、受控眼镜与帽子、表情、姿态、手势、背景功能和色温。短发、刘海、脸型、五官几何、年龄感和肤色必须一致。服装不能退化成两件相近的 T 恤或普通外套；必须同时保持暖黄与深绿的颜色反差、连帽与尖领的领型反差、柔软宽松与挺括多层的剪影反差，并保持“蓝色卡通眼镜、无帽”与“细金属眼镜、深灰报童帽”的配饰反差，确保竖屏小尺寸和静音观看时仍能一眼识别角色。

## Frame Logic

- 9:16 竖屏，人物通常占画面高度的 45%–70%；顶部预留平台安全区，标题放在安全区下方。字幕不是默认必选层。
- 小白与专家用构图方位、色温或小范围布景区分，但不要求固定左右站位；剪辑连续性优先。
- 开头首帧必须同时看见小白和本期问题证据：使用 `project_pain` 对应的问题场景、待处理对象或压力来源；不能先放片名、空背景或人物空讲。
- 各优势点的证据画面优先使用同一观察尺度和同一结果区，形成可比较的版式；每一组都必须肉眼可辨。
- 可信信号拍单独落版一次，视觉上先让观众看见仓库或数据的真实状态，再让专家完成交付。
- 来源博主的外貌、服装、房间、道具、色板、字幕版式和水印都不是固定资产，不进入本胶囊。

## Real Project Media

- 小白与专家露脸段沿用本胶囊固定人物资产。官方 Demo、README、结果图和 GitHub 证据在默认路线中直接使用真实抓取画面：真实 GitHub 页面截图与滚动录屏优先，其次 api.github.com 官方原始素材（raw SVG、GFM 渲染 README 表格），本地合成只在确实无法抓取时兜底；如选 `h3_reference_board`，才先进入对应 H3 参考板，由 H3 生成角色拿起、展示或翻动画面。最终视频不得同时重复叠加两条路线。
- 至少一幕清晰保留 GitHub 或 README 中的项目身份，但裁掉浏览器地址栏、URL、二维码、登录信息、无关侧栏和隐私数据。
- 采集官方仓库和 Demo 时使用真实浏览器定位并抓取素材，但最终成片不展示操作说明、地址栏或额外鼠标动画。真实抓取画面直接作为证据画面使用，不伪造点击后的成功状态。
- 参考板必须保留官方 UI、结果和 Demo 的主体特征，不重绘后冒充来源；H3 可能重构细小文字，因此所有口播事实仍以原始采集和素材清单为准。
- 当本期选择 `clean_title_only` 画面策略时，真实素材直接作为证据主体，不叠加“真实截图”、操作提示、API 采集、来源说明、角色标签、数据卡或字幕；仓库和官方 Demo 原生自带的文字属于素材本身，不做二次解释性文字。
- `clean_title_only` 不使用白色外框，也不把整条成片缩进白色画布。人物段保持全画布；横版仓库或 Demo 进入 H3 参考板时，可用无描边蓝黑金网格补足空白，禁止白色模糊背景，也禁止把素材缩小扔在大画布中央（窗口过小、四周空荡）。
- 证据素材的比例在采集阶段就按目标画布决定：录屏这类可控比例的素材，采集时就用与 9:16 画布宽度对齐的竖向视口（如 1080x1440、DPR 1），落位不再缩放。比例不可控的现成图不模糊垫底：过高图宽度对齐、从上往下平滑下滑展示；过宽图高度对齐内容带、从左往右平滑横移展示。
- 顶部主标题直接叠在画面安全区下方，从 0.00 秒持续到最后一帧、贯穿全部章节不消失，不使用标题卡、白底、色块容器或外层边框；标题可用浅金白文字与轻微暗影保证可读性。
- 大段说明、命令和抽象机制可转换为本地可编辑图形，但必须在画面显著标注“结构示意”，并在素材清单映射到来源事实。
- 每项画面素材都写入 `source_asset_manifest`：来源 URL 或仓库路径、采集时间、类型、用途、哈希、对应主张和是否经过裁切。
