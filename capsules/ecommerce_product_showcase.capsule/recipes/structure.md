# Structure

## structure

- {
  "beat": "0-3s pain or curiosity hook",
  "purpose": "Name a concrete use case or pain point the audience recognizes immediately; product or use context must be visible."
}
- {
  "beat": "3-7s product reveal",
  "purpose": "Show the product clearly, using the user-provided product image as identity reference when available."
}
- {
  "beat": "7-14s key benefit demo",
  "purpose": "Demonstrate one selling point through before/after, close-up action, or scenario proof."
}
- {
  "beat": "14-20s second benefit or objection handling",
  "purpose": "Address portability, ease of use, texture, durability, trust, or a user-supplied proof point without inventing evidence."
}
- {
  "beat": "20-30s soft CTA",
  "purpose": "End with a short action cue such as check details, add to cart, or save for later; include price/promo only if user supplied it."
}
