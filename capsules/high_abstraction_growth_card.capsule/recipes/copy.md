# Copy

## Evidence boundary

- 当前方法来自账号级基线、账号相对高表现样本与近期对照样本，以及逐条全文文案、开场和代表帧分析。证据足以支持跨题材的结构、开场、收藏型命名和视觉机制归纳；逐段动作连续性、完整 BGM/SFX 模型仍是有限证据。
- 可以复用题材组织、论证顺序、信息密度和情绪曲线；不得复制来源文字、账号身份、画面、水印、声音或私有链接。
- 账号高表现与近期对照的主要差异来自选题的**自我投射强度与解释增量**，不是视频做短、换字体或单纯增加动画。视觉和动效只能放大内容，不能挽救弱命题。

## Topic diagnosis before writing

写稿前先确认三件事：谁在当前现实里承受这个压力、观众通常如何解释这个问题、以及这个题目的机制比那个解释多一层，且至少有两个不可互换的具体成人生活场景能证明它。缺少场景、解释增量或可推导动作就将选题降级，不要用“不是 A，而是 B”硬造深度。

从 `life_uncertainty`、`cognitive_control`、`relationship_social`、`growth_reconstruction` 中选一条主路线，以 Lane-specific reasoning 的叙事骨架为准。

## Topic selection

- 角度只选最有货的那个，写出来就用，不凑候选数、不打分、不做两两对决。判断标准是解释中心、证明路径、反方问题或身份收益跟常见做法有真实区别，不只是换同义词。
- 优先选择观众能立刻代入、又能被统一命名的普遍焦虑，例如内在主权、关系信号、认知上限、层级跃迁、不确定性和反馈循环。宏大哲学命题必须能落回至少三个现实场景。
- 谨慎选择纯执行/纯吃苦、天然排除大量观众的窄年龄题、只有宇宙/能量/财富承诺却无法核验的命题、旧内容换词复刻、行动成本高但没有即时认知回报的题材。
- 只有情绪刺激没有解释、只有类比没有逻辑、只有方法没有机制、或标题承诺了正文不回答的问题，换题重写，不硬凑。

## Lane-specific reasoning

### life_uncertainty

适合人生、低谷、命运、意义和失控感。使用：普遍困境 -> 控制幻觉或旧解释 -> 更深法则 -> 证明/类比 -> 面对方式 -> 人生判断。动作可以是心理姿态或选择原则，但必须具体，不能只有“接纳”。

### cognitive_control

适合自控、注意力、时间观、信息环境和内在主权。使用：具体失控场景 -> 意志解释失效 -> 行为层/系统层二分 -> 机制 -> 对比证明 -> 环境或系统动作 -> 从被动执行到主动设计。

### relationship_social

适合识人、沟通、说服、关系边界和社会行为。使用：尴尬或冲突场景 -> 表面评价 -> 隐藏信号/需求/利益结构 -> 2-3 个可观察细节 -> 常见误判 -> 判断或应对方式 -> 成熟关系观。不得强行落到效率或启动系统。

### growth_reconstruction

适合失败、低谷、重建、低水平勤奋和身份升级。使用：反常识人生命题 -> 现实痛点排比 -> 表层损失/深层损失 -> 证明或跨界类比 -> 推翻旧定义 -> 2-3 个重建动作 -> 新身份和金句收束。

## Opening and retention

- 真正 0 秒的第一句必须给判断、具体痛点、身份压力、利益损失或未闭合问题；寒暄、背景、定义和泛泛建议不得作为第一句。
- 第一屏比口播更短，但两者必须表达同一个认知转折。标题负责题材与推荐语境，封面负责停止滑动，三者不能各写一个方向。
- 优先使用可验证的认知反转句式：`你以为……其实……`、`问题不在……而在……`、`真正的……不是……而是……`。每次反转后必须立刻给场景或解释，不能把句式本身当深度。
- 开场之后不能只重复结论。20 秒内至少出现一个具体场景和一个比开场更深的问题；前 20 秒的任务是让观众同时获得“被说中”和“我还不知道答案”的感受。
- 长文案每 15-30 秒至少发生一次认知推进：新场景、新区分、新证据、新反转、新方法、新边界或新身份。纯修辞重复不算推进。
- 每解决一层问题，必须用自然口播打开下一层，例如“可如果问题不在意志，那它到底藏在哪里？”或“这个解释成立，会不会又变成替自己开脱？”问题必须具体，并在后文兑现。
- 不要连续使用同一种强句引擎。`你以为/其实`、`不是/而是`、`问题不在/而在` 任一种在相邻两个 beats 中不得重复。

## Writing the topic so people keep watching

出彩不是把话说得更绝对，而是让观众连续经历七次价值领取：

1. **命名**：准确描述一种观众经历过、却没说清的痛苦。
2. **夺回解释权**：指出大众解释为什么让人更自责，却没有解决问题。
3. **统一**：用一个模型把多个看似不同的场景连起来。
4. **验证**：用对比、案例或跨框架互证让模型不只像金句。
5. **处理反方**：主动回答“这是不是鸡汤、唯心、绝对化或逃避现实”。
6. **可操作**：给 3-7 个机制可追溯的动作，写清触发条件和失败信号。
7. **可复述**：用模型名、二分法、闭环或层级，让观众能保存并讲给别人听。

深度内容的最小全文链路是：`痛点白描 -> 否定不充分的旧解释 -> 提出底层机制 -> 命名模型 -> 跨框架验证 -> 处理反方 -> 3-7 个动作 -> 身份收束`。任何环节如果没有新增解释，就删除而不是靠排比扩写。

## Proof and analogy

- 类比的任务是让抽象机制可见，不是制造“高级感”。必须说明类比的对应关系和边界。
- 不得虚构研究、数据、心理学名词或自然规律。未经核验的科学断言改写成生活观察或明确的可能性表达。
- 同一条视频只选一条主证明路线；长栏目可加入 1-2 个补充框架做互证，但必须分别说明对应关系与边界。证据不足时宁可用可观察对比，也不要把比喻写成事实。
- 引用佛学、道家、心理学、神经科学或商业模型时，必须区分“概念借用、生活观察、已有事实与作者推论”，不能用跨学科名词制造权威感。

## Action and emotional payoff

- 方法必须能回指前文机制。例如前文诊断为环境持续制造临场选择，方法就应减少选择、调整默认项或改变触发条件，而不是泛泛要求更努力。
- 指出残酷问题后必须提供解释性卸压：让观众看见“问题如何形成”，而不是把所有责任压回个人意志。
- 结尾完成身份重定义或价值判断；禁止只用“相信自己、坚持下去、你一定可以”作为收束。
- “真正的……不是……而是……”只在关键认知翻转处使用，连续两段不得复用同一句式。

## Visible text and bold keywords

- 每张卡的 `visible_text` 必须只压缩一个判断，并用 `**...**` 显式标出 **1-2 个完整语义短语**。每个短语建议 2-10 个字，必须能脱离前后半句独立成立；例子只描述形态：`表面是<表层现象>\n深层是**<核心机制>**`。
- 加粗对象优先是模型名、二分两端、因果转折、动作动词、边界条件或身份重定义；不要加粗虚词、情绪副词或整句。
- `emphasis_keywords` 必须与 `**...**` 中的原文逐项一致。禁止强调以“而是、不是、其实、所以、然后、因为”等连接词开头的截断片段，也禁止以“的、地、得、了、和、与”等虚词结尾。渲染器只用更高字重、深一级黑色和极轻微描边呈现，**不加下划线、不改变字号、不单独染红**；Markdown 星号必须从 SVG、可见文字清单和最终画面中移除。
- 同一张卡最多两个加粗锚点；一行超过 60% 字符被加粗视为整句滥用。红色负责主题与机制转折，粗体负责阅读锚点，两者不要把整屏变成高亮。

## Packaging families

候选标题家族包括：人生命题、本质揭示、最高境界、身份跃迁、高手识别和普遍困境。它们只提供组织方式，不提供可直接复用的字面内容。

- 标题必须包含核心概念或清晰痛点语境。
- 封面 1-2 行，承担冲突或损失；标题补足概念和搜索语境，不与封面逐字重复。
- 发布文案补充适用人群、未展开的一层问题或讨论入口，不得只把标题再抄一遍。
- 评论 CTA 优先邀请自我投射、阶段判断、步骤卡点或真实反例，例如“这套结构里，真正卡住你的是哪一步？”；禁止“认同扣 1”、廉价站队和与正文无关的资源诱导。
- 标签服务题材归类；不堆与正文无关的泛流量词。

## Required output

规划必须输出：话题与题材路线、时长模式、受众与现实压力、选中角度、模型名、具体场景、概念二分、证明路线、边界、错误解法、问题升级链、反方处理、推导动作、身份收益、前三秒、前二十秒、完整语义 beats、逐 beat 的信息增量/留存问题/关键词/卡形、完整口播、标题、封面、发布文案、评论 CTA 和风险提醒。
