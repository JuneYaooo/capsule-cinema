# Copy

## Evidence boundary

- 当前可复用证据由一批账号元数据和一条内容完整的长视频组成。`growth_reconstruction` 的完整论证链有多模态证据；其他题材路线是账号元数据支持的候选路线。
- 可以复用题材组织、论证顺序、信息密度和情绪曲线；不得复制来源文字、账号身份、画面、水印、声音或私有链接。
- 候选路线可以用于原创试制，但不能在观众文案中伪装成被普遍验证的定律。

## Topic diagnosis before writing

正式写稿前先完成以下诊断，任何一项缺失都不能直接进入卡片文案：

1. `content_lane`：从 `life_uncertainty`、`cognitive_control`、`relationship_social`、`growth_reconstruction` 中选择一条主路线。
2. `audience`：写清目标观众、当前现实压力和没有被满足的情绪需求。
3. `concrete_scenes`：短论至少两个、深度长文至少三个不可互换的成年人生活场景。
4. `common_belief`：观众通常如何解释这个问题。
5. `hidden_mechanism`：比常见解释多一层、且能解释多个场景的机制。
6. `conceptual_split`：把表层现象与深层机制清楚二分，而不是给原问题换一个抽象同义词。
7. `proof`：选择生活观察、对比、案例、系统类比或经核验的自然/身体类比。
8. `false_solution`：指出观众常用但不能处理深层机制的办法。
9. `actions`：给出 2-3 个从机制直接推导的动作，并标明每个动作解决哪一层问题。
10. `identity_payoff`：把观众从旧的自我评价带到一个更有掌控感、但不过度承诺的新身份。

如果找不到具体场景、解释增量或可推导动作，将选题降级为低潜力；不要用“不是 A，而是 B”硬造深度。

## Angle competition

- 每期至少生成三个真正不同的角度。三个角度应改变解释中心、证明路径或身份收益，不能只是换同义词。
- 每个角度必须记录：角度句、目标观众、现实压力、具体场景、常见解释、深层机制、完成期待、收藏/转发理由、事实或合规风险。
- 使用以下维度做 100 分竞争：现实共鸣 20、解释增量 20、场景具体度 15、反常识合理性 15、证明能力 10、方法可推导性 10、身份收益 5、自然口播 5。
- 任一候选如果只有情绪刺激、没有解释；只有类比、没有逻辑；只有方法、没有机制；或标题承诺了正文不回答的问题，直接淘汰。

## Lane-specific reasoning

### life_uncertainty

适合人生、低谷、命运、意义和失控感。使用：普遍困境 -> 控制幻觉或旧解释 -> 更深法则 -> 证明/类比 -> 面对方式 -> 人生判断。动作可以是心理姿态或选择原则，但必须具体，不能只有“接纳”。

### cognitive_control

适合自控、注意力、时间观、信息环境和内在主权。使用：具体失控场景 -> 意志解释失效 -> 行为层/系统层二分 -> 机制 -> 对比证明 -> 环境或系统动作 -> 从被动执行到主动设计。

### relationship_social

适合识人、沟通、说服、关系边界和社会行为。使用：尴尬或冲突场景 -> 表面评价 -> 隐藏信号/需求/利益结构 -> 2-3 个可观察细节 -> 常见误判 -> 判断或应对方式 -> 成熟关系观。不得强行落到效率或启动系统。

### growth_reconstruction

适合失败、低谷、重建、低水平勤奋和身份升级。使用：反常识人生命题 -> 现实痛点排比 -> 表层损失/深层损失 -> 证明或跨界类比 -> 推翻旧定义 -> 2-3 个重建动作 -> 新身份和金句收束。

## Opening and retention

- 真正 0 秒的第一句必须给判断、具体痛点、身份压力、利益损失或未闭合问题；寒暄、背景、定义和泛泛建议不得作为第一句。
- 第一屏比口播更短，但两者必须表达同一个认知转折。标题负责题材与推荐语境，封面负责停止滑动，三者不能各写一个方向。
- 开场之后不能只重复结论。20 秒内至少出现一个具体场景和一个比开场更深的问题。
- 长文案每 15-30 秒至少发生一次认知推进：新场景、新区分、新证据、新反转、新方法或新身份。纯修辞重复不算推进。

## Proof and analogy

- 类比的任务是让抽象机制可见，不是制造“高级感”。必须说明类比的对应关系和边界。
- 不得虚构研究、数据、心理学名词或自然规律。未经核验的科学断言改写成生活观察或明确的可能性表达。
- 同一条视频只选一条主证明路线；证据不足时宁可用可观察对比，也不要把比喻写成事实。

## Action and emotional payoff

- 方法必须能回指前文机制。例如前文诊断为环境持续制造临场选择，方法就应减少选择、调整默认项或改变触发条件，而不是泛泛要求更努力。
- 指出残酷问题后必须提供解释性卸压：让观众看见“问题如何形成”，而不是把所有责任压回个人意志。
- 结尾完成身份重定义或价值判断；禁止只用“相信自己、坚持下去、你一定可以”作为收束。
- “真正的……不是……而是……”只在关键认知翻转处使用，连续两段不得复用同一句式。

## Packaging families

候选标题家族包括：人生命题、本质揭示、最高境界、身份跃迁、高手识别和普遍困境。它们只提供组织方式，不提供可直接复用的字面内容。

- 标题必须包含核心概念或清晰痛点语境。
- 封面 1-2 行，承担冲突或损失；标题补足概念和搜索语境，不与封面逐字重复。
- 发布文案补充适用人群、未展开的一层问题或讨论入口，不得只把标题再抄一遍。
- 标签服务题材归类；不堆与正文无关的泛流量词。

## Required output

规划必须输出：原始话题、题材路线、时长模式、受众、三个角度候选及评分、选中角度、具体场景、概念二分、证明路线、错误解法、推导动作、身份收益、前三秒、前二十秒、完整语义 beats、逐 beat 口播、完整口播、标题、封面、发布文案和风险提醒。
