# Visual

## Rules

## card_visual_system

- 形式是本地精确渲染的白底图文知识卡，不让图像模型生成中文。
- 画幅默认 1080x1440；用于抖音发布时可居中放入 1080x1920 安全画布。
- 每张卡保留固定视觉骨架：左上原创圆章、中上原创英文/拼音式栏目名、红色主题判断、黑色大判断、英文/拼音式分隔行、右下角观点提示、底部三列灰底栏目带。
- 第一幕不是普通卡形的第一张，而是一张可独立截图传播的冲突海报。第 0 帧必须同时存在完整钩子、核心小人、一个占据中景主位的冲突符号和尚未完成的因果动作；禁止从空白栏目骨架开始淡入。
- 第一幕的图像必须直接可视化标题中的因果，不只做气氛。例如“旧结果开始解释未来”应表现为过去的失败印记、被牵制的小人和正在关闭的未来入口，而不是泛用圆环、雷达或装饰性抽象图。
- 颜色限制在白、黑、浅灰、克制红；不使用原账号 logo、头像、昵称、水印、链接或任何可识别素材。
- 中部插画是核心，不是装饰。每张卡必须有一个和判断语义绑定的 SVG-like 向量隐喻：人物、门槛、路径、圆环、风险雷达、桌面、树、太阳、阶梯、滑杆等元素可组合使用。
- 全片字体基线采用**中高字重**：栏目名、红色主题判断、中央主句、英文分隔行、卡形标签、辅助点和底栏都不能呈现纤细发虚的 Light 观感。中央主句的普通部分使用 Medium 级字重；每张卡 1-2 个由 `**...**` 标记的完整语义短语只提高一级字重，并使用不超过 1px 的同色微描边。关键词不加下划线、不放大、不单独染红；不得把 Markdown 星号渲染出来，也不得整句全部加粗。
- 先根据 beat 的语义选择 `metaphor_family`，再选择组件。可用家族包括：孤立人物、认知负载、隐藏信号、关系距离、边界、双层系统、循环模式、时间跨度、恢复生长、重建路径、环境设计和身份升级。
- 固定的是黑白灰红皮肤、上下栏目框架和中部语义插画位置；不固定的是每期插画顺序。旧单集的门槛、计时器或系统面板不得成为新题材的默认论证顺序。
- 插画要用黑/红/灰的扁平几何语言，线条粗细稳定，留白足够；人物必须是剪影式结构，不能是火柴人或矩形身体加四条线；红色路径/弧线负责表达“机制正在发生”。
- 全片默认复用同一个原创核心小人 `mind_walker`：黑色圆头、弧形黑色躯干、无脸剪影、红色小围巾和稳定头身比不变；每卡只改变姿势、朝向、位置、手中道具与所处路径状态。它不是角落装饰，而是观众的投射代理，必须参与当前卡的因果关系。
- 角色状态要沿论证继承：受困段可以迟疑、停步、抱头或被信息压住；机制段观察、对比、记录；行动段拿事实卡、沿新路径移动；身份段站直或登阶。不得每张卡重新发明一个不同人物，也不得只复制同一站姿换背景。
- 每张 SVG 资产要能声明可复审的组件族：`person_silhouette`、`red_path_or_arc`、`environment_symbol`，解释系统重构时还要包含 `system_panel`。
- 中部场景需要有四层：**背景结构**建立空间与关系，**主隐喻**承担核心判断，至少 2 个**语义道具**补足场景与因果，**红色路径/弧线**指出变化方向。不能只放进度条、圆圈或无意义抽象形状，也不能为了丰富而把每个名词变成一个图标。
- 自绘组件库应覆盖山势、道路、旗帜、树木、积木、任务卡、关系区域、对话框、边界柱、信号波、碎片、双层面板、分叉、路障、罗盘、太阳、时间轴、循环节点、系统网络和身份阶梯。每期按语义组合，不固定顺序。
- 默认素材路线是 `self_drawn_local_vector`：中部图像优先由本地 PIL/SVG 几何组件生成，保证线宽、圆角、配色、动画拆层和授权一致。**默认不去网上拼图标**。
- 只有当专业对象无法被现有组件准确表达时，才允许使用外部图标；必须同时满足：许可明确、文件本地打包、记录作者/来源/许可、去除品牌识别、重绘为黑灰红统一线宽，并能拆成动画层。搜索结果截图、未知许可 SVG、平台贴纸和图标字体不得进入胶囊。
- 每张卡按论证任务选择一种结构形态，连续最多两张相同：
  - `verdict_poster`：用于开场反转，最大字号、强留白、单一冲突隐喻。
  - `scene_card`：用于现实场景，人物与环境占主位，文字更克制。
  - `dual_compare`：用于表层/深层、旧解释/新解释、拥有/成为等二分，画面有明确左右或上下对照。
  - `model_map`：用于机制、闭环、层级与跨框架互证，出现节点、连接或系统面板。
  - `question_card`：用于真实反方或下一层问题，使用问号、断点或未闭合路径，不伪装成答案。
  - `action_path`：用于 3-7 步方法，显示当前序号、动作方向与机制连接。
  - `identity_poster`：用于结尾身份重定义，减少辅助信息，形成可截图保存的终局判断。
- **信息丰富不等于每屏堆字**。单卡只显示一个主判断，可用 0-3 个 `supporting_points` 辅助：场景卡放地点/行为标签，二分卡放两端标签，模型卡放节点名，动作卡放条件或失败信号。每个辅助点不超过 12 个汉字。
- 长栏目每 60-90 秒至少切换一次信息形态：场景 -> 二分 -> 模型 -> 反方 -> 方法 -> 身份。不得十几分钟只用“中央句子 + 同尺寸插画”的单一节奏。
- 允许复刻的是视觉机制和布局语法，禁止复制的是原账号名称、原 logo、原水印、原链接、原视频帧、原画面中的专属文字或可识别素材。
- 运行时要单独导出每张卡的 SVG 语义资产，方便复审中部插画是否真的被写出。
- SVG 必须保留 `data-card-form`、`data-emphasis-keywords` 和语义组件族元数据，便于复审关键词粗体、卡形轮换与插画对应关系。
- 底部三列使用跨题材栏目语义：现实场景/先被看见、机制拆解/获得解释、行动重建/身份升级；不得写入某一单集的具体解法。
