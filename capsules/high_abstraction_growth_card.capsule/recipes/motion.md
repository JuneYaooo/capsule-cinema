# Motion

## Rules

## local_card_motion

- 运动以卡片切换加中部插画揭示为主；卡间硬切或语义匹配轻切，卡内元素按“判断 -> 结构 -> 关键词 -> 结果”分阶段进入。卡片时长由逐 beat 的预计秒数、权重或口播长度决定，不做平均分配。
- 开头 0-3 秒必须同时出现红色主题判断、黑色大判断和语义中图的启动动作，不能只有静态文字。
- 每张卡默认采用覆盖完整口播的三阶段演示：0%-28% 立即建立判断与初始困境；18%-72% 让人物、主隐喻、道具和路径发生因果变化；58%-97% 让红色追踪点、节点反馈、人物位移或结论状态继续完成。最后只保留约 3% 稳定落点，不得把前 55% 做成动画、后 45% 强制静止。
- 第一幕第 0 帧直接显示完整主判断、核心小人和冲突初态；0-3 秒负责让因果动作发生，而不是等待文字和角色逐个淡入。普通卡片也必须以至少 8% 的初始构图进入，避免切卡时闪回空白 PPT 模板。
- 关键词强调只发生一次，不循环呼吸、不持续放大；加粗是常驻层级，动画只是帮助眼睛落点。
- 卡形决定转场语义：`dual_compare` 用分隔线展开，`model_map` 用节点连线，`question_card` 用未闭合弧线或断点，`action_path` 用路径推进和序号锁定，`identity_poster` 用逐步减法与稳定停留。
- 相邻 beats 共享同一模型时，保留红色路径或核心节点做 match cut；论证发生层级跃迁时使用干净硬切。不得为“丰富”而随机旋转、弹跳或套用炫技转场。
- 卡间默认使用约 0.18 秒轻量融合，并继承上一卡的小人朝向、红色路径或节点之一；转场时间不能长到产生双重文字残影，也不能用整页飞入、翻页或缩放等 PPT 动效。
- 核心小人采用角色状态继承：上一卡的朝向、移动方向或手中道具至少保留一个到下一卡，再改变姿势或环境。例如“停在路障前 -> 被信息云压住 -> 观察双层系统 -> 拿起事实卡 -> 沿红色新路径前进 -> 登上身份阶梯”。角色在卡内的位移必须服务因果，不做无意义循环走动。
- 一个 beat 明显超过可读时长时先拆分语义，不用延长静止画面掩盖文案过密；切卡必须落在句意边界。
- 单卡超过 18 秒时必须至少有第二视觉状态，例如从现象层切到机制层、从问题态切到答案态；若没有第二状态，必须拆卡。
- 重点不是炫技转场，而是让观众在读判断的同时看见一个可记忆的结构隐喻。
- 正式视频必须有可听见的原创口播和低音量 BGM，不允许静音 AAC 或只靠本地预览音轨冒充成片。
- 第一张卡必须承担前三秒停留，不出现任何参考账号相关文字或水印。
