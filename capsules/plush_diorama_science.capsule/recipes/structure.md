# 结构与画面切换

这一类片子讲的都是「一个看不见的过程」：东西是怎么来的、怎么变的、为什么会这样。观众要看懂的是一条因果链，所以结构的第一原则是：**画面每切一次，因果链就往前走一格**。不往前走的镜头，再好看也删掉。

## 怎么用这份配方

- **底线，每期都守**：因果链一句推一句；三个画面世界各管各的事；主容器状态只往前走；只在字幕段边界切；动作和音效挂在关键词上；主体不压标题带和字幕带；文案先确认再生产；成片听写验收；响度达标。
- **默认值，按本期调**：时长、镜头数、三个世界的占比、各种秒数和电平、原型和隐喻道具的具体样子。这些是参考片实测出来的起点，不是指标。
- **不要逐条照抄成模板**：同一个原型，每期换角色、换容器、换动作细节；镜头节奏跟着这一期的台本走，哪里信息密就切得快，哪里要让观众看清变化就多停一会儿。

## 一、先判断题目能不能做

适合的题目同时满足三条：

1. 有一个**具体的成品或结果**，名字一说观众就知道（某种食物、某个现象、某种材料）。它就是片子的 payoff，最后要被举起来。
2. 过程可以拆成 **5–10 个因果步骤**，每一步都能用「谁 + 做了什么 + 所以怎样」说清楚。
3. 过程发生在**一个容器或一个地方**里（洞、缸、罐、身体里、土里、锅里）。它就是主容器，后面会被剖开。

不适合：新闻和时效信息、要靠真实影像当证据的、观点争论、人物访谈、需要照片级真实感的题目。也不适合「十个冷知识」这种并列清单，因为没有链条，三个画面世界就搭不起来。

## 二、叙事骨架（六段）

| 段 | 作用 | 时长参考（80 秒片） | 写法要点 |
|---|---|---|---|
| 钩子 | 场景 + 秘密路径 + 传说结果 | 约 6 秒，2–3 句话 | 第一句就把观众放进场景，第三句说出成品名字 |
| 「原来」 | 揭开动机：谁、为什么、做了什么 | 约 10 秒 | 用「原来，」开口，把钩子里的秘密打开 |
| 因果步骤 | 第 1 步到第 N 步 | 占全片 2/3 | 每步一个章节牌，一步 1–2 句 |
| 类比 | 「相当于一个……」 | 嵌在步骤里，1 句 | 把抽象条件换成观众家里有的东西 |
| 揭晓 | 「这，就是 X。」 | 1.5 秒，单独一句 | 前后各多停一拍，全片最响的一下 |
| 收尾提醒 | 风险或冷知识反转 | 约 6 秒 | 「不过……所以……千万别……」，收在全景 |

揭晓句一定要单独成句、单独成镜。它前面要有一个「香气 / 成色 / 完成」的镜头做铺垫，让观众先感到「成了」，再听到名字。

## 三、时长与字数预算

- 目标 60–90 秒。口播语速按每秒 5.3 字左右算（MiniMax 1.0 倍速、含句内停顿），**全片约 400 字配 80 秒**。超了就删句子，绝不后期加速。
- 一句话 1–5 个字幕段，一段 3–15 个字；全片 12–16 句。
- 镜头数约为字幕段数的 70%：80 秒大约 30 个镜头，平均 2.6 秒一个，最短 1 秒，最长 4.5 秒。

## 四、三个画面世界

整片只在三个世界之间切换。每个世界有固定的任务，观众很快就会学会「看到哪种画面，就在听哪种信息」。

1. **角色世界**：毛绒角色在微缩布景里活动。负责**动机和结果**——谁想要什么、做了什么、最后得到什么。开场、动机、揭晓、收尾都在这里。
2. **剖面世界**：同一个主容器被纵向剖开，剖面朝镜头。负责**内部发生了什么**——东西进去、被压、液面上涨、颜色变化、微观角色出现。
3. **实验台**：干净的台面上放玩具分子、仪表、标牌、开关。负责**抽象机制**——分解、结合、切换、一降一升、到达上限。

在 80 秒的参考片里，三个世界的时长大约是角色 38%、剖面 37%、实验台 25%。

**交替规则**

- 开场在角色世界连续停留 5–7 个镜头（钩子 + 动机），让观众先认识角色和主容器。
- 进入步骤后，剖面和实验台交替，每 2–3 个镜头换一次世界，同一个世界最多连续 3 个镜头。
- 隔一阵回一次角色世界（理想是 10–20 秒，最长不超过 30 秒），哪怕只有 1 个镜头（时间流逝、角色等待、闻到香味），提醒观众「这件事是谁在做」。
- 揭晓和收尾回到角色世界，并且和开场呼应：同一批角色、同一个主容器、同一片布景。

## 五、主容器接力（连续性的关键）

主容器是全片的「地点」。它必须：

- 在钩子里**先出现外观**，在剖面世界里**再被剖开**，观众才认得出「还是那个地方」。
- 用 3 种可见状态充当**进度条**：装了多少（填充量）、液面高度、颜色。剖面每出现一次，状态必须接着上一次，不能倒退，也不能凭空跳变。
- 状态变化挂在口播关键词上：说「渗出」时液面开始涨，说「稀释」时颜色变浅，说「有害」时变浑。

写分镜时给每个剖面镜头标一行「入场状态 → 出场状态」，下一次进剖面就从这个出场状态开始。

## 六、画面隐喻词典

口播里一出现这些意思，就用对应的画面。它们是这个系列观众已经认识的「词汇」，换题目也照用：

| 口播的意思 | 画面 |
|---|---|
| 密闭、封住 | 一把锁啪地弹出 |
| 稳定、刚好 | 温度计 / 指针冲过去再稳住，停在绿区 |
| 相当于、就像 | 容器旁浮出同形状的人造物，中间一个「=」 |
| 微观的东西出现 | 推近表面，原来是一颗颗带脸的小毛球，眨眼 |
| 繁殖、增多 | 1→2→4→8→16 啵啵分裂 |
| 分解、拆开 | 微观角色跳起来咬一口，分子玩具断成两半 |
| 结合、反应生成 | 两个分子从两边靠拢，闪光一下变成新分子 |
| 时间流逝 | 叶子掉落、颜色褪掉、光从暖变冷，越走越快的钟声 |
| 堵住、断绝 | 一团软泥塞进开口 |
| 缺少某样东西 | 红色禁止徽章，中间是那样东西 |
| 切换模式、开启 | 拨杆开关从一盏灯拨到另一盏灯 |
| 一边减少一边增加 | 两根量筒一降一升，箭头弹出 |
| 到达上限 | 刻度计冲进红色带，旁边角色醉晕、打嗝 |
| 停止、死亡 | 角色变灰、X 眼、倒下，气泡停，停止牌 |
| 香气、诱惑 | 金色卷须从开口飘出，角色闻到闭眼冒爱心 |
| 揭晓、成功 | 主角举起成品，朋友欢呼跳，镜头快推慢停，大字贴纸 |
| 危险、有害 | 深色刺球坏角色冒出来，液体变浑绿冒泡；朋友按住主角摇头，禁止牌 |

词典里没有的意思，照同一个原则新造：**找一个小孩玩具里就有的东西，让它在说到那个词的瞬间做一个动作**。

## 七、镜头什么时候切

- **只在字幕段边界切**，切点比这一段人声提前 0.08 秒（PRECUT），画面先到、声音跟上，感觉更利落。不在一个字幕段中间切。
- 一个字幕段说一件事、一个画面。如果一段里有两个关键词，就让同一个镜头里先后发生两个动作，不要硬切。
- 镜头短于 1 秒不切，合并到相邻镜头；长于 4.5 秒就在下一个字幕段切开，或者在镜头里加第二个动作。
- 切换世界时，前后两个镜头的主体尽量落在画面同一区域，眼睛不用找。
- 原型库（套件 `templates/shots.py`）里每个原型对应一种镜头任务，分镜表里每个镜头先写它用哪个原型，再写本期的替换内容：
  - 角色世界：trot_in（小碎步开场）、peek（偷看）、discover（发现与预告）、motive_gather / motive_need（动机）、time_lapse（时间流逝）、aroma（香气）、reveal（揭晓）、stop_sign（劝阻收尾）
  - 剖面世界：cutaway_fill（落进容器）、cutaway_rise（液面上涨）、split（分裂繁殖）、plug（堵住）、lack_badge（缺少）、die_off（停止、死亡）、warning（坏东西冒出来）
  - 实验台：condition（条件）、analogy（相当于）、macro_reveal（推近看到微观角色）、meter（冲到上限）、mode_switch（切换模式）、molecule_split（分解）、molecule_merge（结合）、level_compare（一降一升）

## 八、分镜表的格式

每个镜头一行：

`镜头 id | 起点（句号.段号）| 世界 | 原型 | 画面一句话 | 关键词 → 动作 | 主容器状态（入 → 出）| 标签`

先写分镜表、再写 shots.py。分镜表和台本一起给人确认。
