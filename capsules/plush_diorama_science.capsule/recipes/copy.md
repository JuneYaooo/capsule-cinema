# 文案

这一类片子的文案只有一个任务：**让观众不看画面也能听懂一条因果链，看了画面就记住**。不煽情、不铺垫、不讲道理，每一句都在推进「然后发生了什么」。

## 一、素材来源与核实

1. 用户常给一条参考视频的口播。先把它转写出来（ASR 会有错字，比如同音字、断句错），逐句改成通顺的书面句。
2. **逐条核实科学事实**，不照抄参考片。参考片常见的错误：步骤顺序颠倒、把两个过程混成一个、数值记错、因果说反。改掉的地方要单独列出来告诉用户：原句、改法、依据。
3. 连接词收紧：删掉「然后呢」「其实」「那么」「我们知道」这类空词，换成「而且」「这时」「等到」「可是」这种推进因果的词。
4. 数字要有来源；查不到可靠来源的数字，宁可改成定性说法（「到了一定浓度」）。

## 二、台本骨架

照 structure 的六段写，每段的句式如下（`<>` 换成本期内容）：

- **钩子（2–3 句）**：「如果你在<场景>遇到<角色>，」「只要<秘密路径>，」「八成就能找到传说中的<成品>。」
  第一句就要有画面感的场景，第三句一定说出成品名。不要用「你知道吗」「今天带你了解」开头。
- **「原来」（1–2 句）**：「原来，<角色>到了<时机>，为了<动机>，就会<动作>。」把钩子里的秘密打开，交代主容器。
- **因果步骤（每步 1–2 句）**：主语 + 动作 + 结果。「<东西>不断<动作>，<结果>。」
  - 每一句都回应上一句：上一句的结果是这一句的起因。只读台词、不看画面念一遍，能一句接一句地听下去，才算通过。
  - 条件句用「而」「这时」「等到」引出；转折用「可」「不过」。
- **类比（1 句）**：「相当于一个<观众家里有的东西>。」只用一次，放在最抽象的那个条件后面。
- **揭晓（1 句）**：「这，就是<成品>。」逗号后停一拍，名字单独落下。
- **收尾提醒（1–2 句）**：「不过<风险>，」「所以这种<成品>，千万别<危险行为>！」或者一个反转冷知识。不说教、不总结。

## 三、信息密度

- 开头 6 秒内必须出现：场景、主角、成品名。
- 步骤里说具体的东西（名称、数值、条件），不说「一系列复杂的变化」这种空话。
- 情绪和闲聊算废话：「太神奇了」「是不是很有意思」都删。
- 平台名不进口播，需要时说「自媒体平台」。

## 四、字幕段切分

- 一句话按停顿切成 1–5 个字幕段，每段 3–15 个字。切点放在逗号处，**一个意群一段**，不要把一个词拆到两段。
- 上屏时句末的「，。、」删掉，句中的逗号换成两个空格。
- 每句挑 **1–5 个高亮词**：名词性的关键概念、数值、动作结果。高亮词说到的时候变黄并弹一下，画面上的关键动作也挂在同一个词上，所以高亮词就是「画面动作的锚点」。挑词时想一想：这个词出来时画面能做什么动作？做不出动作的词不高亮。

## 五、读法和上屏分开写

TTS 只看读法，观众只看上屏。两者不同时写成 `(读法, 上屏)`：

- 数字、百分号、范围：读「百分之十二到十五」，上屏「12%~15%」。
- 化学式、单位、符号：读汉字全称。**两套字体都没有 ₂ ↑ → ↓ ⚠ ℃ 这些字形**（会显示成方块），上屏也写汉字：写「氧气」不写「O₂」，写「摄氏度」不写「℃」，升降用画面里的箭头道具表达。标题字体（庆科黄油体）还缺「·」，数字字形也不好看，所以**带数字的牌子、标签都用字幕字体**，标题带和揭晓贴字尽量只放汉字。叠字脚本合成前会自动查缺字，查到就停。
- 多音字、容易读错的词：读法里换成不会读错的同义写法，上屏保留原词。

## 六、标题、章节牌、标签、封面

- **一句话贯穿**：常驻标题带 = 封面大字 = 发布标题，都是同一句「<成品关键词> + 问句」，比如「<X>是怎么来的？」。关键词用暖黄，问句用奶油白。
- **章节牌**：每个因果步骤一张，格式「第 N 步 · <5 个字的动作结果>」，比如「第 3 步 · <容器>变<作用>」。揭晓用一张金色的「<成了>」，提醒用一张红色的「注意！」。五个字以内说清这一步干了什么。
- **跟物体走的标签**：只给观众第一次见到的东西起名字（新物质、新角色、类比物、数值），每个镜头最多 3 个。标签文字必须和口播里的词一致。
- **揭晓贴字**：只有一个，就是成品名加感叹号。
- **发布文案**：标题同上；正文两三句说清「看完你会知道什么」，再加 3–5 个话题标签。不写「建议收藏」之类的套话。

## 七、先确认，再生产

以下全部写完后一次性给用户确认，**确认之前不合成配音、不渲染**：

1. 台本（每句的读法和上屏、字幕段、高亮词）
2. 改掉的事实错误清单（原句 → 改法 → 依据）
3. 标题带 / 封面字 / 发布标题（同一句）
4. 章节牌列表
5. 标签列表
6. 分镜表（见 structure）
7. 发布文案

用户改了任何一处，同步改 episode.py 里对应的字段，再往下走。

## 八、交付前的文字检查

- 全部可见文字按码点检查零宽字符（U+200B 一类），不要从显示文本里复制产品名或专有名词。
- 成片用两个 ASR 模型全片转写，对照台本逐句比（见 audio）。
