# 动效与剪辑节奏

动效的总原则：**每个动作都有一个「为什么现在动」的理由，理由就是口播刚好说到那个词**。没有理由的晃动、漂浮、转圈都是噪音。

## 一、关键词锚定

- 时间线给每个镜头一张事件表：`kw:<词>` 关键词时刻、`c<句>.<段>` 字幕段开口、`end<句>` 句末，单位是镜头内秒数。
- 动作的关键帧一律写成「事件时间 + 偏移」，不写死秒数。配音一换、时间线一重排，动画自动跟上。
- 偏移的习惯：
  - 弹出类（标牌、锁、分子、标签）在关键词前 0.1–0.2 秒开始，关键词时刻正好弹到最大。
  - 变化类（液面、颜色、指针）从关键词前 0.3–0.6 秒开始，关键词后 0.3–0.5 秒到位。
  - 断裂、咬断、拨开关这种瞬间动作，提前 0.25 秒发生，让观众先看到再听到名字。
  - 预告类（发光、香气）提前 0.6 秒慢慢起来，说到名字时最亮。
- 一个镜头里有两个关键词，就安排两个动作，先后发生。

## 二、缓动词汇表

| 缓动 | 用在哪 | 感觉 |
|---|---|---|
| ease_out_back（回弹 1.7） | 一切「出现」：标牌、标签、分子、角色探头、成品弹出 | 弹出来稍微冲过头再回来，玩具感 |
| smoothstep | 液面、颜色、灯光、指针、角色姿态过渡 | 匀而软 |
| ease_in_out | 相机推拉、物体沿路径移动 | 起停都柔和 |
| ease_out_cubic（快进慢停） | 揭晓推镜、推近特写 | 冲上去再稳住 |
| 弹跳落地 | 小东西从上面掉下来 | 落地后弹两下，越弹越低 |
| 阻尼摆动 sin·e^(−kt) | 禁止牌、贴字、容器被「拍一下」 | 晃两下停住 |
| 线性 | 跟拍角色平移、时钟、循环的气泡和雨 | 稳定 |

## 三、角色与道具的动作语法

- **小碎步**：步态相位 = 时间 × 11（约每秒 3.5 步）；两条腿反相前后摆 ±0.55 弧度，手臂反向摆，身体上下弹 3%、左右晃 0.07 弧度。几只角色排队走时相位依次错开约 1.1，不要同步。
- **眨眼**：每 2–3 秒一次，持续 0.1 秒左右；几个角色错开相位。静止的角色也要眨眼，画面才「活」。
- **开心**：开心眼 + 腮红变亮 + 原地小跳。**醉 / 晕**：身体左右摇、腮红变红、眼睛半闭再变晕眼。**死**：变灰、X 眼、侧倒下沉。
- **出现**：从 0 缩放到 1，用 ease_out_back；一群东西依次出现，每个间隔 0.04–0.18 秒，不要一起出现。
- **消失**：缩放到 1e-4，0.15–0.3 秒；液体里的东西可以淡出。
- **繁殖**：第 n 代从父代的位置分裂出来，沿直线滑到自己的位置。
- **挤压**：体积大致不变——纵向压扁的同时横向撑开（z 缩 35%、x 胀 18%）。
- **容器「被拍一下」**：纵向 1 + 0.06·sin(18t)·e^(−4t)，横向按 1/√ 补偿，晃两下停。

## 四、相机运动

**默认固定机位和焦段，让角色、道具和因果变化承担动作。** 每次运镜必须交代它揭示了什么新信息；“让画面动起来”不是理由。禁止给每镜套同一段微弱慢推，也不默认同时缩短相机距离和增加焦段。

| 镜头任务 | 相机与剪辑方式 |
|---|---|
| 解释变化、展示比较 | 固定机位，保留观察参照；关键词驱动物体变化 |
| 强调细节、反应、结果 | 在字幕段边界硬切到有明确差异的景别或观察角度，重新安排视觉重点 |
| 跟随走动角色 | 只沿运动方向平移，速度和角色一致，保持距离、焦段与主体屏幕位置 |
| 揭示此前看不清的细节、揭晓成品 | 可用一次短推进，关键词附近启动，通常 0.25–0.6 秒到位，再稳定停留 |
| 收尾交代整体关系 | 可用一次 0.5–1.0 秒的后拉，露出完整布景后停住 |

- 运镜的起点、终点和停留都写进分镜；起动时间挂在关键词事件上。焦段保持固定，特殊光学变化需单独说明用途。
- 不把所有镜头机械换成快推、左右摇或环绕。相邻镜头不得无信息增量地重复同方向运动；固定镜头之间也要避免相同构图的无效重复。
- 硬切靠景别、动作阶段和信息重点建立节奏，不加叠化或划像。动作完成后给观众看清结果的时间，不为追求镜头数提前截断。
- 断裂、弹开等瞬间变化可从 0.2–0.45 秒的主体动作起步调节；液面、状态对照等过程按理解需要留时，不统一加速。冲击可用短促、衰减的小幅抖动，只有在冲击瞬间需要时使用。
- 插入特写或反应镜头时沿用同一事件时间和物体状态；切回后接着演，不能从零重新播放同一变化。

套件中普通原型用 `L.aim_camera` 固定构图，跟拍只更新横向位置；需要短运镜时调用 `cam_move(cam, t - start, duration, ...)`，用事件计算 `start`，起止焦段相同。函数会在运动区间前后保持端点。

## 五、叠字层的动效

叠字层在渲染帧上用 PIL 合成，坐标以 1080×1920 为准。字体：字幕、章节牌、标签用 ZCOOL 快乐体，标题和贴字用庆科黄油体（两者都随胶囊打包，SIL OFL 1.1）。合成前先用字体的字符表查一遍全部上屏文字，有缺字就停下改字，不要带着方块出片。

**常驻标题**
- 标题带中线 y=258，104 px，描边 9，深棕描边 `(58, 42, 32)` + 柔和投影。
- 开场 0.35 秒从 0.85 倍弹到 1 倍（ease_out_back），之后全片常驻、不动。

**章节牌**
- 圆角药丸，y=342，40 px 白字（描边 3）。底色：步骤橙 `#e9893a`、揭晓金 `#dba128`、提醒红 `#d9473b`。
- 在该句第一个字幕段前 0.1 秒切换，0.3 秒从 0.3 倍弹到 1 倍，同时放一声「咻」。

**字幕**
- 字幕带中线 y=1405，68 px 白字，描边 6 + 投影；超过 980 px 宽就整体缩小字号，不换行。
- 比人声早 2 帧上屏；人声结束后 0.35 秒下屏，和下一段间隔不到 0.5 秒就直接接上；最后一段留到片尾。
- 关键词说到前 0.05 秒变黄 `#ffd23f`，同时往上跳 14 px、放大 1.1 倍，0.22 秒跳完落回原位保持黄色。跳的时候底下那一行留出空位，避免一个词画两遍。

**跟物体走的标签**
- 44 px 药丸牌，底色奶油 `#fff3d6`（或者和所指物体同色系的浅色），深棕描边。
- 锚点是 3D 物体的位置，每帧投影到屏幕坐标，所以物体动、标签跟着动。标签相对锚点偏移时画一条引线（7 px 深棕 + 3 px 奶油）和一个锚点圆点。
- 0.28 秒弹出（ease_out_back），0.15 秒收起；位置限制在 y 400–1290 之间，左右不出画。

**揭晓贴字**
- 庆科黄油体 150 px 暖黄 `#ffc23f`，放在画面上部（y≈470）。
- 0.35 秒弹出，同时从 −12° 转正，再加一个衰减摆动 6·sin(12t)·e^(−4t)。

**封面**
- 揭晓镜头里主角举起成品那一帧，加上和标题带同一句的大字：关键词一行 230 px，问句一行 140 px。

## 六、运镜与节奏验收

- 记录每镜的机位类型、景别、运动理由、关键词锚点、起止时间及到位后的停留。固定镜头检查相机位置、朝向与焦段全程不变；运动镜头检查到位后是否确实停止。
- 正片批量渲染前，用连续帧预览最难动作及其前后镜头，配上对应口播正常速度播放。首、中、尾三张预览图只能检查构图，不能代替节奏验收。
- 成片连续播放开头、解释密集段、关键变化和结尾，检查重复慢推、等动作的空拍、无意义切换、动作重启、细节看不清和字幕抢视线。记录检查时间段、问题与修复结果。
- 固定机位不等于画面卡死。对冻结检测逐项核对：为理解结果保留的有限停留可以通过；预期动作没发生、帧序列停更或意外冻结到片尾必须修复。不要为消除冻结告警添加无意义运镜。
- 联系表和编码、音频指标通过后，仍需完成以上人工连续播放检查；技术分数不能代替节奏判断。

## 七、编码与出片检查

- 帧是 PIL 合成的 JPEG（全范围、bt601 矩阵），编码时显式转成 bt709 有限范围 yuv420p，并把色彩信息写进码流：
  `scale=in_range=full:in_color_matrix=bt601:out_range=tv:out_color_matrix=bt709:flags=lanczos+accurate_rnd+full_chroma_int,format=yuv420p,setsar=1`，
  再加 `-bsf:v h264_metadata=colour_primaries=1:transfer_characteristics=1:matrix_coefficients=1`（只设 -color_primaries 不会写进码流）。
- libx264 slow、crf 17、high profile、tune animation；AAC 256k；faststart。
- 检查清单：SAR 1:1、色彩标记三项都是 bt709、帧数等于时间线、响度 −14 LUFS、真峰值不超过 −1 dBTP、音轨和混音文件的偏移小于半帧（21 毫秒）。
- **验颜色要显式按 bt709 解码再比**：ffmpeg 默认解回 RGB 会按 601 解，整体看起来暗 2 级左右，那是解码端的问题，不是片子的问题。
- 抽帧联系表看不出画面被压扁，所以 SAR 一定要用 ffprobe 查。
