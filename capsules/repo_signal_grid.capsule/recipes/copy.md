# Copy

## repo_signal_grid_structured_evidence_copy

Signal Grid 是两行标题。第一行先甩一句人话判断，第二行是项目名加 Stars 加一个核心能力。Stars 是可信度钩子，写进第二行主标题，不推副标题。15 秒足够把悬念开大，后面用真实项目画面慢慢接住。

**Stars 数不高时（<5000）**：行1 用人话判断或项目动作（"这一步终于有自动化了"），行2 照旧。Stars 仍然写，但让行1 承担停留任务。

### 人话钩子底稿

- `旧资料还在一页页抄？这套东西就是干这个的。`
- `Agent 最容易漏的，偏偏是权限。`
- `写这一步的报价，真得重新算。`
- `我把一份需求丢进去，它一路做到了交付包。`
- `会聊天不稀奇。能把活交出来才算。`
- `这个 repo 不大，但正好补了我最烦的那一步。`

第二行用正常人认识的类型，比如 `文档转 Skill`、`生产接入检查`、`PPT 生成`。别写“准确项目类型、交付缺口、证据反差”这种后台话。

### 片内文案

1. 第一页给用户判断和项目身份。
2. 第二页讲旧做法或卡点。
3. 第三页讲项目最特别的动作。
4. 第四页放真实结果。
5. 最后一页给选择条件或边界。

截图证明事实，示意图只帮人看懂关系。标题可以晚一点完全兑现，但整条视频必须把答案讲出来。

创作完成后，只执行共享参考里的最低必要合规检查。除此之外，不评分，不凑候选，不做证据卡，不因为标题狠而改软。
