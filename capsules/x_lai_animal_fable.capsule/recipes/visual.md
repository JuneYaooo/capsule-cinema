# Visual

## Visual Grammar

- 目标是“旧游戏过场/早期国产低成本 3D 动画”：基础几何、低分辨率重复贴图、均匀平光、生硬绑定和略突兀的虚拟镜头，不是现代精致卡通电影，也不是故意做烂的网络滤镜。
- 主角是低多边形拟人动物：默认采用早期业余 3D 动画常见的直立人形躯干、短粗四肢和动物头部，动物轮廓与物种特征清楚，眉毛、眼球、口鼻像分别装上的廉价几何零件，但不变成穿动物头套的人。用户明确要求自然四足时才切换为四足轮廓。
- 救场主角不必固定为动物，但必须直接实体化X和宣传对象：动物X使用同物种角色；物件X使用拟人物件；服务/活动使用真实载体、核心参与者或经授权的品牌角色。
- 默认采用 `X世界一致性`：所有有脸、会说话或承担剧情的角色都属于同一个X视觉家族。弱势角色与救场角色是不同个体，不是不同语义物种。例如“书来”用小书受困、大书救场，整镜不得出现山羊、狗、猫头鹰或人；“羊来”才使用羊角色。无生命背景道具可以不同，但不能形成第二角色IP。
- 几何体必须真正低面数并看得见折面，避免圆润毛绒质感；局部关节和面部比例略僵，眼球、眼皮、眉毛、嘴唇和口鼻可呈现零件拼装感。山、草、树皮可故意复用同一张低清纹理并产生明显拉伸，与原始几何形成不协调。
- 使用发白且曝光不匀的均匀平光、极弱或错误方向的阴影、无景深、高饱和但互不协调的蓝绿黄红色块。皮肤和衣物像廉价哑光塑料或低清贴图，不要精致毛发、皮毛微细节、全局光照、漂亮散景、柔和轮廓光和豪华体积光。
- 开场可用贴脸近景或完整怪相全身景；呼唤后允许一次硬切、突兀快速推镜或粗糙烟雾遮挡，禁止连续顺滑运镜。
- 背景使用低清贴图山丘、重复球形树冠、纯色天空和少量岩石，空间关系要简单到一眼读懂。

## Controlled Imperfection

- 每镜设计一个主要可读瑕疵，并允许一个伴随的短暂穿模：`<关节方向略错>`、`<重心不合理>`、`<嘴型过度人化>`、`<手臂轻微穿过躯干>`、`<蹄子短暂陷入地面>` 或 `<两角色交叉动作时肩膀短暂互穿>`。
- 穿模必须是低成本绑定造成的局部、短暂、可逆错误，且服务当前动作；穿模前后角色数量、头部、四肢总数和牛的身份必须稳定。可以让关节穿插，不能随机增生肢体、融脸、断头、完全合体、文字乱码，也不能用强噪点或 VHS/glitch 滤镜代替真正粗糙的 3D 建模与动画。
- 画面仍需满足：主角可辨认、动作可辨认、障碍可辨认、后果可辨认。

## Roughness Acceptance Test

- 静帧必须同时读出至少四项：可见折面、零件式五官、低清拉伸贴图、发白平光、简单球形/块状环境、僵硬绑定姿势、局部短暂穿模。
- 若静帧像现代手机游戏宣传、精致 3D 插画、圆润玩具动画、写实动物摄影或带柔光景深的电影卡通，即使主体正确也判为风格失败。
- 粗糙来自模型、材质、绑定、灯光和镜头共同的不成熟，不通过后期降清晰度、加噪点、屏摄边框或水印伪造。

## Character Soft Lock

- 为主角写一个不含本期动作的完整 `character_anchor`，包括物种、体型、头身比、毛色/皮肤、面部、服装、关键配件和材质。
- 每个 Agnes 图片和视频提示词逐字复用同一 `character_anchor`，只在其后追加场景、动作、镜头和光线。
- 同样为重要配角使用独立文本锚点，不在中途改颜色、服装或年龄描述。
- 救场主角锚点必须包含 `xlai_entity_marker` 和 `promotion_visual_anchor`：前者证明它就是X，后者证明它与宣传内容有关。二者应落在物种、轮廓、本体、服装或关键道具上，不能只写抽象性格。
- Agnes 当前不能用角色参考图驱动视频，也不支持首尾帧锁定。这里仅能声明“文本锚点软锁定”，不能声称严格一致。
- 在剪辑上把可能的外形漂移放到真实硬切、视点变化或时间跳跃处，不依赖跨请求的精确空间连续性。

## Prompt Shape

每个视觉提示词按以下顺序组织：

`<character_anchor> + <simple repeated-texture environment> + <first-frame oddity> + <summon/reveal/payoff action> + <solemn or forceful emotion> + <fixed camera plus at most one hard cut/fast push> + <early low-budget 3D game-cutscene grammar> + <no brand/logo/watermark>`

提示词在救场镜还必须逐字写明：`<X实体可见特征> + <宣传对象可见锚点> + <X特有的单一解决动作>`。不要依赖模型理解“某动物象征某概念”。

生成提示不得引用现有作品名、角色名、原对白、原镜头或创作者身份。复刻的是抽象机制，不是复制可识别表达。

## Route Choice

- 动作事故是本镜核心时优先 `AgnesVideoGeneratorTool` 文生视频。
- 建立环境、见证反应、庄重余味等低动作场景优先 `AgnesImageGeneratorTool` 文生图，再做本地静态持镜或极轻推镜。
- 先看首镜样片，再决定是收紧动作描述、降低动作数量，还是把该镜降级为图片持镜；不自动切换到其他云端提供商。
