# Copy

## Rules

## second_person_voiceover

- 正文默认使用第二人称，让观众即主角；核心句式是“你出生在/你醒来时/你第一次发现/你以为/你决定/你终于/你后来才知道”。
- 开场身份锁定优先使用短句：“每天一个模拟人生，今天你抽到的是<主题短名>的一生。”、“如果你的人生随机重开，这一局是<主题短名>的一生。”、“这一集，你抽到<主题短名>的一生。”。
- 片头身份锁定句只能出现在 opening.tts；正文口播脚本必须写入 body_narration_script，并从身份锁定后的第一个处境/动作/感官细节开始，不能把同一句开场再放进正文 TTS。
- 正文口播句子要服务画面切换：一句话没说完不能频繁换图；优先写成可让一个画面覆盖 1-2 句的短句群。超长句可以拆成多个画面，但要在语义分句或自然停顿处切，并让多个画面保持同一句内的动作/空间/情绪连续。
- 旁白要让观众在当下经历处境，而不是听完一个人的履历；禁止写成旁观式传记，避免长期使用“他/她/这个人/主角后来”推进正文。
- 第三人称只允许短暂作为外部压力或反差来源，例如“他们都觉得你疯了”“老板只看见报表”；叙事重心必须立刻回到“你”的感受、动作和选择。
- 每期必须出现选择-后果链：你遇到压力，你做出一个带欲望或侥幸的选择，你得到短暂爽点或错觉，代价反噬回来，你被迫面对结果。
- 每 10-15 秒写入一个身体感、空间感或生活细节锚点，例如手机震动、钥匙硌手、门锁咔哒一声、出租屋灯闪、工牌勒住脖子、账单弹窗、手心出汗、地铁玻璃里的倒影、凌晨电脑蓝光。
- 结尾不说教，不写“这个故事告诉我们”；用一个具体现场收住，例如“你盯着手机上最后一条未读消息，突然不敢点开。”

## viral_life_sim_script

- 写正式稿前必须先写 3 个 hook 备选，并做真实第一句审查：真正 0 秒听到的第一句必须已经制造痛点、身份压迫、反常识、极端利益或强烈冲突；不能只在标题或内部备注里有 hook。
- 每期必须有 `content_force_card`：一句话说明“这条让观众相信什么”、痛点/敌人是谁、观众能获得的爽感/警醒/控制感是什么、为什么会想转发或收藏。
- 正文必须有一个明确压力源或敌人：老板、算法、评论区、同学、饭局、贫穷、虚荣、规则、欲望、骗局或现实。没有压力源的口播容易变成知识总结，必须重写。
- 结构优先走“高压处境 -> 荒诞选择/执念 -> 短暂爽点或错觉 -> 现实反噬 -> 公开处刑/反转 -> 生活余味”。爽点可以是反杀、打脸、暴富、翻盘、被现实打醒或看别人翻车，但必须有情绪释放。
- 语言要有参考账号式的具体刺点：金额、时间、温度、身体反应、粗糙触感、手机弹窗、房间气味、道具状态、旁人眼神。抽象词后面必须跟一个能看见的动作或物件。
- 禁止泛泛建议型稿子，例如“你要关注用户”“你要提高信息密度”“你要坚持输出”。如果必须表达方法论，要把它改写成剧情现场：你删掉哪一句、谁划走了你、哪条评论把你钉住。
- 不追求温和正确，追求可听完：每 8-12 秒至少要有一个痛点、反转、具体细节、动作选择、羞耻感、爽点或悬念钩子。
- 参考账号只学习结构和情绪机制，不照抄具体桥段、侮辱性称呼或高风险现实身份。风险词要换成更安全但仍有冲突的表达。

## reference_style_brief

- 当输入 `reference_account_analysis_path` 时，先产出 `reference_style_brief`，再写脚本。brief 至少包含：最强 hook 模式、观众情绪、选题标签、爽点类型、视觉 DNA、口播密度、可复用细节、风险边界。
- `reference_style_brief` 只能进入内部规划，不应原样出现在观众可见文案里。
- 若参考账号是“人生副本/社会奇观/爽文审判”类型，life_sim 应优先采用第二人称沉浸式短剧，不要写成创作者讲课或旁观式人物小传。

## copy_guardrails

- 禁止把正文写成百科式人物小传、命运概括、人生建议或价值观总结。
- 禁止用空泛代入词糊弄观众，例如只说“你很难过”“你很痛苦”，却不给具体动作、物件、声音或空间压力。
- 禁止让开场只像抽签游戏；抽到的身份必须马上变成“你这一局要面对的处境”。
- 封面、标题和发布文案可以保留“每天一个模拟人生”的系列感，但正文口播必须优先服务沉浸式第二人称体验。
