# Hook And Format Taxonomy

Use this taxonomy to tag winners consistently. Add local tags when evidence demands it, but keep the base tags stable for cross-account comparison.

## AI Content Lanes

- `ai_news`: model releases, company updates, financing, policy, benchmarks.
- `ai_tools`: tool discovery, tool stacks, comparisons, productivity workflows.
- `ai_open_source`: GitHub repos, models, frameworks, local deployment, benchmarks.
- `ai_tutorial`: how-to, prompt recipes, automation, build walkthroughs.
- `ai_workflow`: multi-tool pipelines, agent workflows, templates, operations.
- `ai_opinion`: industry judgment, career impact, founder/developer perspective.
- `ai_case`: before/after examples, business use cases, creator use cases.
- `ai_resource`: lists, cheat sheets, repo packs, prompts, websites.

## Hook Mechanisms

- `breaking_news`: something just happened and timing matters.
- `result_first`: show the result before explaining the process.
- `tool_saves_time`: promise hours saved, fewer steps, automation, or lower cost.
- `hidden_resource`: rare repo/site/tool/template most viewers have not seen.
- `comparison`: A vs B, old way vs new way, paid vs free, local vs cloud.
- `contrarian`: challenges a common belief or hype narrative.
- `risk_warning`: avoid a trap, scam, obsolete tool, wrong workflow, or career risk.
- `identity_pressure`: developers, students, creators, founders, operators should care.
- `numbers_proof`: stars, downloads, benchmarks, cost, speed, revenue, users.
- `demo_shock`: visual output is surprising enough to stop scrolling.
- `curiosity_gap`: a missing answer the viewer wants resolved.
- `authority_signal`: cites reputable lab/company/repo/person/data.
- `comment_bait_resource`: invites comment for a list, prompt, repo, or template.

## Short-Video Structures

- `news_to_impact`: news -> why it matters -> who is affected -> what to do.
- `tool_demo`: pain -> result -> tool -> steps -> use case -> save/share CTA.
- `repo_breakdown`: repo proof -> what it does -> why it matters -> install/use -> caveat.
- `workflow_recipe`: outcome -> stack -> step sequence -> bottleneck solved -> template CTA.
- `comparison_review`: old/new or A/B -> criteria -> winner by use case -> caveats.
- `myth_bust`: common belief -> contradiction -> evidence -> practical rule.
- `listicle`: top N -> fast proof for each -> selection rule -> resource CTA.
- `case_rebuild`: example result -> reverse-engineer process -> transferable pattern.

## Interaction Drivers

- `save_for_later`: dense tutorial/resource/checklist.
- `ask_for_resource`: comment keyword to get link/prompt/list.
- `debate`: opinion, ranking, controversial claim.
- `identity_signal`: viewers comment to show role, stack, or stance.
- `troubleshooting`: viewers ask how to reproduce/fix errors.
- `fear_of_missing_out`: fast-changing AI update or limited access.
- `showcase_envy`: result looks impressive enough to share.

## First-5-Second Audit

For every winner, answer:

1. What exactly appears in the first frame?
2. What is the first readable text?
3. What is the first audible or implied claim?
4. What viewer self-interest is triggered?
5. What evidence appears before second 5?
6. Would the hook still work muted?
7. Would the hook still work audio-only?
8. What is the retention gap opened by second 3?
