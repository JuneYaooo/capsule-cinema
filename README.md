# Capsule Cinema 胶囊影厂

用对话把一个想法做成可复用、可质检的 AI 短视频。你给目标、素材和偏好，AI 选择合适的「视频胶囊」或通用流程，完成分镜、画面、视频、配音、BGM、字幕、拼接、质检和后续复用沉淀。

它不只是生成一次视频；它会把一次跑通的作品变成以后能继续生产的配方。适合想快速出片、反复打磨同一类内容、把成功经验保存下来复用的人。

## 你能得到什么

| 用户关心的事 | Capsule Cinema 怎么解决 |
|--------------|--------------------------|
| 我只想说需求，不想研究工具链 | 直接用自然语言说明主题、人群、风格、素材，AI 会路由到分镜、生成、拼接或胶囊流程 |
| 我怕一次生成不满意 | 可以先只看分镜，也可以只重做某个分镜、只换 BGM、只重拼已有素材 |
| 我想保持同一类视频稳定产出 | 把满意作品保存成胶囊，沉淀风格、结构、节奏、资产和质量规则 |
| 我关心能不能发布 | 成片后会生成本地质检报告、质量评分、修复计划和发布检查点 |
| 我有专门场景，不想每次从零说 | 使用内置胶囊，例如仓库展示、电商带货、治愈 ASMR、剧情口播、国风讲解；动作迁移、数字人口播、角色 MV 走专用能力路线 |

## 最快开始

安装 Capsule Cinema 后，直接在对话里说目标即可：

> 用 Capsule Cinema 做一个 30 秒竖屏短视频，主题是 `<主题>`，目标观众是 `<人群>`，风格要 `<风格>`。

更可控的说法：

| 想做什么 | 对 AI 这样说 |
|----------|--------------|
| 先看方案 | “先只生成分镜，不要生成图片、视频和配音。主题是 `<主题>`，我确认后再继续制作。” |
| 做完整成片 | “用 Capsule Cinema 做一个 `<时长>` 秒 `<横屏/竖屏>` 视频，主题是 `<主题>`，重点突出 `<价值点>`。” |
| 改某个镜头 | “上一次视频第 `<编号>` 个分镜不满意，请保留其他部分，只重做这个分镜：`<修改要求>`。” |
| 复用已有素材 | “这些分镜素材已经可以了，请重新拼接，并按新的字幕/BGM/节奏要求调整最终成片。” |
| 检查能不能发 | “请检查这个成片是否可发布，重点看画面、声音、字幕、时长、语言匹配和胶囊质检规则。” |
| 保存成配方 | “这条视频我满意，请保存成 `<胶囊名>` 胶囊，适合以后做 `<适用场景>`。” |

如果不确定怎么选，直接说：

> 请先查看 Capsule Cinema 的初始胶囊，根据我的目标推荐一个胶囊，并说明还需要我补哪些素材。

### 新增工具

需要接入新渠道、新工具或新胶囊时，也可以直接用自然语言说明接口文档、目标流程和示例交互。

- “帮我新增一个 `<工具/渠道名>`，接口文档如下：`<粘贴文档>`。请注册完整流程、补测试，并写一个简单用户示例。”
- “帮我安装或启用 `<胶囊名>` 胶囊。README 里不用展示样片，只写用户怎么用自然语言点名它。”
- “这个工具以后用户可以这样说：`<一句用户示例>`。请按这个交互方式同步文档。”

## 把好作品变成胶囊

当一条视频已经跑通、风格满意、后续还想继续做同类内容时，让 AI 保存胶囊即可。AI 会从成片、分镜、提示词、素材、BGM、质检报告和修改反馈里提炼可复用部分。

常用说法：

- “这条视频我满意。请把这次工作流保存成一个新胶囊，名字叫 `<胶囊名>`。”
- “这次是在 `<已有胶囊名>` 基础上做出来的，请把更好的改动沉淀回这个胶囊。”
- “请保存成胶囊，但不要保存客户资料、私密文件、一次性链接、账号信息或任何密钥。”
- “请把这个胶囊整理成可分享版本，先检查敏感信息和不可分发素材。”

胶囊只保留**可复用的不变量**，不保留某一次运行的具体产物：

- **保留(不变量)**：目标人群、适用/不适用场景、默认画幅和时长、分镜结构、固定开场/钩子模式、视觉风格、音频策略、质量规则、已知坑和修复方法，以及真正每期都复用的固定素材（如固定 BGM、字幕字体、固定片头音效）。
- **每期会变(变量)**：主题和该主题下的具体内容，由 AI 每次按你的需求重新生成，不写死进胶囊。
- **只当示例**：某一期用过的具体文案/词，只作「示例」留存并标注「按主题重做」，不会被直接照搬。
- **不保留**：某次的成片、那一期的角色/场景图、这一期的具体措辞、运行产物的绝对路径，以及客户项目、一次性新闻正文、临时链接、密钥、cookie、私有接口、不可授权素材。

固定素材分两种语义：`reuse=always`（每期必用，如固定 BGM）与 `reference_only`（仅风格参考，每期重做）。这条「不变量 vs 一次性内容」的边界由 `doctor` 自动校验。完整数据结构、角色枚举与校验规则见 [`references/local-capsule-sqlite.md`](references/local-capsule-sqlite.md)。
